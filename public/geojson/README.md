# 地图数据说明（public/geojson/china.json）

## 来源
- 数据文件：`china.json`
- 来源服务：阿里云 DataV.GeoAtlas
- 接口地址：`https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`
- 数据内容：中华人民共和国全国边界（adcode 100000，含 34 个省级行政区要素及南海诸岛线要素，共 35 个 features）

## 用途
- 仅作为本项目**开发阶段**的 ECharts 地图底图使用。

## 合规声明
- 上线前必须复核地图数据的合规性（测绘资质、审图号、边界表达等）。
- **不得修改其中任何边界数据**（包括各省边界与南海诸岛线）。
- 若正式对外发布，应改用具有法定资质的地图服务或经审核的标准地图。
